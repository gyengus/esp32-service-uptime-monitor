After Flashing: 3 Quick Steps

Zero manual file uploads — the embedded Web UI extracts automatically on first boot.

1

Connect to Wi-Fi

Configure credentials in the Improv Wi-Fi prompt, or join the open AP ESP32-Service-Uptime-Monitor-XXXXXX and open 192.168.4.1.

2

Open the Dashboard

Visit http://esp32-service-uptime-monitor.local/ (or the device's DHCP IP) to view live service cards and logs.

3

Unlock Settings via BOOT

Short-press the physical BOOT button to unlock configuration for 10 minutes. Hold ≥ 10s for a full Factory Reset.

Key Features

Engineered for reliability on constrained microcontrollers.

HTTP & HTTPS Checks

Runs non-blocking checks on Core 0 with 3-retry hysteresis before triggering an offline state, avoiding false alarms and unnecessary flash writes.

Discord Webhooks

Sends rich embed notifications to your Discord channel only when a service transitions between ONLINE and OFFLINE.

Live WebSocket UI

Responsive Bootstrap 5 dashboard with dark mode, instant status filtering, system telemetry (heap, RSSI, temp), and live log streaming.

Interactive Swagger API

Full OpenAPI 3 specification served both on-device at /api/docs and statically right here on GitHub Pages.

Security Hardened

Physical BOOT button authorization, 10-minute auto-lock, SSRF address validation, DNS rebinding protection, and OTA token rate-limiting.

Wireless OTA & Backup

Update firmware or web assets over HTTP/PlatformIO, and export or restore full JSON configuration snapshots anytime.

RGB LED Status Indicators

Instant visual feedback on boards equipped with a WS2812B RGB LED (HAS_RGB_LED).

Off — All services online
Pulsing Magenta — Service(s) offline
Pulsing Amber — Setup AP mode active
Pulsing Red — Storage / critical error
Cyan — LED brightness test
